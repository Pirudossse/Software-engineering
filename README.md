# Software Engineering

Ce dépôt regroupe deux projets distincts :

- **[Full DevOps Lab](Full_DevOps_Lab/README.md)** : exercices JavaScript et API Healthcare (médecins, patients, rendez-vous et métriques), avec tests, Postman et intégration continue. Le [compte rendu du lab](Full_DevOps_Lab/RAPPORT.md), ses captures et l’archive sont conservés dans ce dossier.
- **[Campus Room Booking](Campus_Room_Booking/README.md)** : application de réservation de salles du Campus du Parc, avec ses API, tests et collections Postman.

Chaque projet possède son propre `package.json`. Pour l’installer et le lancer, suivre son README depuis le dossier correspondant.
